# Đấu Trường 4 Nhóm Cố Định - Đường Cao Trên Lưới Ô Vuông

Bao gồm 4 trò chơi (mỗi trò 4–5 vòng) dành cho 4 nhóm cố định, tích hợp sẵn các cơ chế khắc phục lỗi vận hành phổ biến trên lớp, máy tính và điện thoại.

## Cách đưa lên GitHub Pages
1. Giải nén file `.zip` để lấy `index.html`.
2. Tạo repository mới trên GitHub và tải `index.html` lên thư mục gốc.
3. Vào **Settings -> Pages**, chọn nhánh chính (`main`) và thư mục `/ (root)`, bấm **Save**.
4. Mở đường link GitHub Pages trên máy tính hoặc điện thoại để sử dụng.
